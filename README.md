# MadameDataIT.com

Site vitrine de Lavinia Bulgarean-Haiduc, consultante IA & automatisation (« Je réalise ton projet »).

🌐 Site live : https://madamedatait.com

## Pages
- `index.html` : accueil et 4 offres
- `services.html` : détail des offres
- `sites.html` : création de sites web
- `portfolio.html` : projets
- `contact.html` / `merci.html` : formulaire de contact

Les adresses sont sans `.html` (GitHub Pages).

## Dossiers
- `streamlit_*` : applications de démonstration du portfolio (déployées sur Streamlit Cloud)
- `portfolio-projects/` : notebooks et documentation des projets
- `assets/`, `images/` : PDF et visuels du site

## Stack technique
- HTML5 / CSS3, police Poppins auto-hébergée
- Hébergement : GitHub Pages, domaine via `CNAME`
- SEO : `sitemap.xml`, `robots.txt`, balises meta et JSON-LD
